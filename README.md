# Transcriber

Настольное приложение: видео или аудио → текст. ffmpeg вытаскивает и чистит звук,
faster-whisper распознаёт речь, на выходе — оформленный документ.

**Всё считается на этом компьютере.** В сеть уходят только скачивания моделей и
ffmpeg. Ни одна секунда записи никуда не отправляется — для лекций, созвонов и
интервью это главное отличие от онлайн-сервисов.

## Зачем это

Чтобы расшифровать часовую лекцию, обычно нужно: вытащить звук через ffmpeg,
вспомнить нужные ключи, скормить файл whisper, дождаться, вычистить результат.
Готовые программы либо просят загрузить запись на чужой сервер, либо умеют один
файл за раз и отдают сырой текст без оформления.

Здесь всё это собрано в одном окне: очередь из десятка записей, понятные
настройки, видимый ход работы, документ на выходе — и возможность в любой момент
остановиться, не потеряв посчитанное.

Мера скорости: на видеокарте RTX 5070 Ti с моделью `large-v3` час записи
превращается в текст примерно за пять минут.

## Что уже работает

- **Очередь**: выбор файлов диалогом, папкой целиком или перетаскиванием в окно.
  Для каждой записи видно длительность, размер и звуковые дорожки; если дорожек
  несколько — можно выбрать нужную.
- **Настройки перед запуском**: шумоподавление, выравнивание громкости, обрезка
  тишины по краям, язык записи, модель, устройство (видеокарта или процессор).
- **Что нужно на выходе**: текст, звуковой файл или и то и другое. Звук —
  в WAV 16 кГц моно, WAV 48 кГц стерео, MP3 или M4A.
- **Ход работы**: пять стадий, крупный процент, оценка оставшегося времени.
  Две остановки: мягкая доводит текущий файл, жёсткая прерывает сейчас — и
  сохраняет то, что успело посчитаться.
- **Скачивание модели** прямо из работы, с процентом и мегабайтами.
- **Результат**: вердикт проверки на повторы, числа (сегменты, слова, скорость),
  кнопки «открыть документ» и «показать папку».
- **Две темы** (светлая, тёмная, как в системе) и **два языка интерфейса**
  (русский, английский).
- **Командная строка** поверх того же ядра — удобна для пакетной работы.

## Чего ещё нет

- документы кроме `txt` — md, docx и субтитры ждут этапа M5;
- экраны «Хранилище» и «Диагностика» — этап M4;
- докачка прерванной загрузки модели;
- подписи у сборок: Windows и macOS ругаются на первый запуск — этап M7.

План этапов целиком — в [docs/architecture.md](docs/architecture.md).

## Установка

Готовые сборки — на странице
[Releases](https://github.com/Deokti/Transcriber/releases). Python и ffmpeg для
них не нужны: ffmpeg и модель программа скачивает сама при первом запуске.

| Система | Что качать |
|---|---|
| Windows | `...-windows-amd64-setup.exe` — установщик, ставится в профиль пользователя, права администратора не нужны. Он с поддержкой видеокарты, отсюда и вес: библиотеки CUDA занимают больше самой программы. Без видеокарты NVIDIA работает так же, просто считает на процессоре. |
| Windows, если важен вес | `...-cpu.zip` (139 МБ) — то же самое без поддержки видеокарты: распаковать и запустить. Есть и `...-cuda.zip`, если видеокарта нужна, а устанавливать не хочется. |
| macOS | `...-macos-*.dmg` — открыть и перетащить программу в «Программы». `arm64` для маков на Apple Silicon, `x86_64` для интеловских. |
| Linux | `...-linux-amd64-cpu.tar.gz` — распаковать куда угодно и запустить `Transcriber-cpu`. Рядом лежит `install.sh`: он добавляет программу в меню. |

### Первый запуск

Сборки не подписаны (подпись — этап M7), поэтому система при первом запуске
предупредит, что не знает эту программу:

- **macOS** — правой кнопкой по программе → «Открыть» → в окне ещё раз
  «Открыть». Дальше она запускается обычным способом. Если пункт не помог:
  «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно
  открыть».
- **Windows** — SmartScreen покажет синее окно: «Подробнее» → «Выполнить
  в любом случае».
- **Linux** — если права на запуск потерялись при распаковке:
  `chmod +x Transcriber-cpu`.

### Проверить, что скачалось целиком

Рядом со сборками лежит `SHA256SUMS.txt`. Посчитать сумму своего файла и
сравнить строку:

```bash
shasum -a 256 Transcriber-0.1.0-macos-arm64-cpu.dmg   # macOS
sha256sum Transcriber-0.1.0-linux-amd64-cpu.tar.gz    # Linux
```

```
certutil -hashfile Transcriber-0.1.0-windows-amd64-cpu.zip SHA256
```

## Как устроено

```
окно (QML)  ──►  мосты (app/bridge)  ──►  ядро (core)
командная строка (cli)  ───────────────►  ядро (core)
```

**Ядро ничего не знает об интерфейсе.** Оно возвращает коды событий и числа, а
слова к ним подбирает тот, кто показывает: окно берёт их из `app/i18n/*.json`,
командная строка — из `cli/messages.py`. Поэтому перевод интерфейса не требует
правок в ядре, а ядро одинаково обслуживает обоих.

Работа одной записи идёт по стадиям, и набор стадий собирается из заказа:

| Что заказали | Стадии |
|---|---|
| Текст | разбор → подготовка звука → распознавание → проверка → выдача → уборка |
| Только звук | разбор → подготовка звука → сохранение файла |
| Текст и звук | то же, что первое, плюс сохранение звука сразу после подготовки |

Счёт идёт в рабочем потоке за фасадом `JobRunner`, события приходят оттуда же и
переезжают в поток окна сигналами Qt. Сегменты пишутся на диск по мере появления
(`.segments.jsonl`), поэтому обрыв на семидесятой минуте не теряет семьдесят
минут работы.

Подробности — в [docs/architecture.md](docs/architecture.md); почему выбраны
именно эти решения — в [docs/adr/](docs/adr).

## Технологии

| Что | Чем | Почему |
|---|---|---|
| Язык | Python 3.12 | faster-whisper существует только для Python, и тяжёлая часть всё равно осталась бы питоновской — [ADR-0001](docs/adr/0001-language-and-stack.md) |
| Интерфейс | PySide6, Qt Quick (QML) | декларативное описание, отрисовка на видеокарте, свой стиль вместо подражания каждой ОС — [ADR-0002](docs/adr/0002-qml-vs-widgets-vs-web.md) |
| Распознавание | faster-whisper (CTranslate2) | в несколько раз быстрее оригинального whisper при том же качестве |
| Звук | ffmpeg | извлечение дорожки, фильтры, перекодирование |

## Запуск для разработки

Нужен **Python 3.12**. ffmpeg и модели программа скачивает сама, но если они
уже есть — возьмёт готовые. Видеокарта не обязательна: без неё всё считается
на процессоре, просто дольше.

```bash
git clone https://github.com/Deokti/Transcriber.git && cd Transcriber
python -m venv .venv
.venv\Scripts\activate           # macOS и Linux: source .venv/bin/activate
pip install -r requirements.txt
pip install -r requirements-dev.txt   # нужен только для сборки и проверки стиля
```

**ffmpeg** ищется в папке данных приложения, в `PATH` и в нескольких привычных
местах (`C:\ffmpeg\bin`, `/usr/local/bin`, `/opt/homebrew/bin`). Если он лежит
где-то ещё — путь указывается в настройках приложения.

**Модели** скачиваются сами при первом запуске: `large-v3` весит около 3 ГБ.
Папку для них тоже можно сменить в настройках — например, указать на уже
скачанный кеш HuggingFace.

## Команды

Всё запускается из корня проекта интерпретатором из окружения: на Windows это
`.venv\Scripts\python.exe`, на macOS и Linux — `.venv/bin/python`. Дальше для
краткости просто `python`.

### Пока пишешь код

| Команда | Что делает |
|---|---|
| `python -m app.main` | окно как оно есть у человека |
| `python -m app.main --watch` | то же, но правка QML подхватывается на лету: окно пересобирает себя, а мосты остаются прежними — очередь файлов и опрошенное окружение не нужно набирать заново |
| `python -m cli lecture.mkv` | то же ядро без окна, удобно когда правишь конвейер |

Ключи окна, все для разработки:

| Ключ | Зачем |
|---|---|
| `--watch` | перечитывать разметку при каждой правке |
| `--screen main\|settings\|progress\|result` | открыть сразу нужный экран |
| `--light`, `--dark` | принудительная тема, мимо настроек |
| `--ui-lang ru\|en` | язык интерфейса на один запуск |
| `--shot файл.png` | отрисовать окно, сохранить картинку и выйти |

### Когда проверяешь сделанное

```bash
python tests/run_all.py                      # все тесты, каждый своим процессом
python tests/test_queue_takes_urls.py        # один тест, когда чинишь его же
```

Снимок экрана без окна — быстрый способ посмотреть вёрстку, не отрываясь
от терминала:

```bash
QT_QPA_PLATFORM=offscreen python -m app.main --shot out.png --light
```

Правило тестов: тест заводится из настоящей ошибки и один раз прогоняется на
сломанном коде — тест, который зеленеет всегда, хуже отсутствующего.
Подробности — в [tests/README.md](tests/README.md).

Проверка стиля и мёртвого кода:

```bash
python -m ruff check core app cli tools tests
```

### Когда собираешь выпуск

Собирается только под ту систему, на которой запущено: PyInstaller не умеет
кросс-сборку, поэтому маковский образ делается на маке, а линуксовый архив —
на линуксе. Всё складывается в `release/`.

| Команда | Что получается |
|---|---|
| `python tools/build.py` | обычная сборка: архив с программой |
| `python tools/build.py --cuda` | сборка с библиотеками CUDA (Windows, Linux) |
| `python tools/build.py --cuda --installer` | она же плюс установщик для Windows |
| `python tools/build.py --all` | обе подряд |
| `python tools/build.py --sums` | только пересчитать `SHA256SUMS.txt` — например, когда в `release/` положили образ, собранный на другой машине |
| `python tools/make_icons.py` | пересобрать значки из `app/icons/*.svg` под все три системы |

### Разовое и обслуживание

| Команда | Что делает |
|---|---|
| `python -m cli --list-models` | каталог моделей: вес, языки, скорость, качество |
| `python -m cli --get-ffmpeg` | скачать ffmpeg в папку данных приложения |
| `python -m cli --save-settings --models-dir D:\Models` | запомнить папку моделей для следующих запусков |
| `python -m cli --save-profile быстро.json …` | сохранить набор ключей пресетом |
| `python -m cli --profile быстро.json запись.mkv` | взять настройки из пресета |

Примеры работы из командной строки:

```bash
python -m cli "D:\Video\*.mkv" --lang ru --denoise medium
python -m cli D:\Lectures --audio-only --audio-format mp3 -o D:\Sound
python -m cli запись.mkv --with-audio --trim-silence --force
```

Полный список ключей — `python -m cli --help`.

## Где что лежит

```
app/     окно: точка входа, мосты к ядру, QML, переводы, значки
cli/     командная строка поверх того же ядра
core/    ядро: конвейер, стадии, движок распознавания, работа с ffmpeg
docs/    требования, архитектура, дизайн-бриф, ADR, соглашение о коммитах
tests/   тесты интерфейса
tools/   вспомогательное: сборка значков
```

## Данные приложения

Модели, журналы и промежуточные файлы живут в стандартной папке пользователя:

- Windows — `%LOCALAPPDATA%\Transcriber`
- macOS — `~/Library/Application Support/Transcriber`
- Linux — `~/.local/share/Transcriber`

Если рядом с программой положить файл с именем `portable`, всё переедет
в её собственную папку `data` — так удобно носить на флешке.

Промежуточный WAV после работы удаляется; это поведение выбирается до запуска,
в блоке «Дополнительно».
