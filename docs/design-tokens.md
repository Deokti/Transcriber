Снято с макетов 16.09.2026. Это то, что превращается в `app/qml/Theme.qml` и в каталоги
переводов почти дословно. Значения менять здесь, а не в коде: файл — источник правды
для внешнего вида.

## 2. Шрифты и размеры

Шрифт системный: Segoe UI Variable на Windows, SF Pro на macOS, Noto Sans на Linux.

| Размер / насыщенность | Где |
|---|---|
| 46 / 600 | процент во время работы — видно с другого конца комнаты |
| 26 / 600 | заголовок экрана результата |
| 19 / 600 | заголовок раздела |
| 15 / 600 | заголовок сообщения |
| 14 / 400 | имена файлов, кнопка «Запустить» |
| 13 / 400 | базовый размер: поля, кнопки, списки |
| 12 / 400 | подписи и строка состояния — мельче не бывает |
| 12 моноширинный | тайм-коды, пути, журнал |

Строка объяснения — не шире 70 символов (примерно 520 px при 13 px). Все надписи
переживают удлинение в полтора раза: панели тянутся, кнопки растут по содержимому,
ни одна колонка с текстом не фиксирована по ширине.

| Высота | Что |
|---|---|
| 32 | поле, выпадающий список |

Панели отделяются рамкой и фоном, без теней.

## 4. Иконки

SVG, обводка 1,5 при размере 14–16 px. В главном сценарии всегда с подписью.

`check` готово, проверка пройдена · `warning` замечание, повторы, нет звука ·
`error` ошибка, работа оборвалась · `info` пояснение к выключенному пункту ·
`running` стадия идёт, медиафайл · `waiting` стадия ждёт своей очереди ·
`download` скачать модель, ffmpeg · `folder` показать папку, выбрать папку ·
`delete` удалить модель, убрать файл · `expand` свёрнутый блок «Дополнительно» ·
`dropdown` стрелка выпадающего списка · `settings` настройки, пресеты

## 5. Стадии

Пять видимых стадий. Разбор файла (`probe`) человеку не показывается — он мгновенный.

| Показывается | Стадия в коде |
|---|---|
| Готовлю звук | `prepare` |
| Распознаю речь | `transcribe` |
| Проверяю текст на повторы | `check` |
| Собираю документ | `export` |
| Убираю за собой | `cleanup` |

Извлечение и чистка звука — один проход ffmpeg, поэтому одна стадия, а не две.

## 6. Тексты сообщений

Правило: **что случилось + почему + что нажать**. Ниже — привязка к кодам событий
из `core/events.py`. Отмеченных **[нет]** кодов в ядре пока не существует.

| Код | Текст | Кнопки |
|---|---|---|
| `FFMPEG_MISSING` | Не найден ffmpeg. Без него не получится вытащить звук из видео — распознавание не запустится. Нужную сборку можно скачать сразу, это 42 МБ. | Скачать — 42 МБ · Указать путь вручную |
| `MODEL_MISSING` | Модель large-v3-turbo ещё не скачана — 1,6 ГБ. Скачаю и сразу начну работу, это добавит около 4 минут. | Скачать и запустить · Выбрать другую модель |
| **[нет]** `MODEL_LANGUAGE_MISMATCH` | distil-large-v3 понимает только английский, а язык записи — русский. Пункт остаётся в списке, но выбрать его нельзя: выберите модель на 99 языков. | пункт неактивен, не спрятан |
| `CUDA_UNAVAILABLE`, `DEVICE_FALLBACK` | Видеокарта недоступна, посчитаю на процессоре. Это займёт примерно втрое больше времени: не 19 минут, а около часа. | Запустить на процессоре · Открыть диагностику |
| `NO_CUDA_ON_MACOS` | На Mac выбор недоступен: движок умеет работать с видеокартами только через CUDA. Посчитаю на процессоре — примерно втрое дольше. | пункт выключен, с пояснением |
| `NO_AUDIO_TRACK` | В файле нет звуковой дорожки — распознавать нечего. Пропущу этот файл и пойду дальше по очереди. | Убрать из очереди · Выбрать другой файл |
| `QUALITY_STUCK` | Найдены повторы — 3 места. В них модель залипла и повторила фразу несколько раз подряд; обычно так бывает на музыке, аплодисментах или долгой тишине. Места указаны таймкодами. | Показать первое место |
| **[нет]** `JOB_ABORTED` | Работа оборвалась на 57%. Видеокарта перестала отвечать — драйвер сбросил контекст на 41-й минуте. Распознанное записано в документ и помечено как неполное. | Досчитать на процессоре · Повторить файл |
| **[нет]** `DOWNLOAD_FAILED` | Загрузка сорвалась на 210 МБ: нет сети. Скачанная часть сохранена — продолжу с этого места, когда сеть вернётся. | Повторить · Убрать из загрузок |
| `DISK_FULL` | На диске свободно 1,8 ГБ, а трёхчасовой записи нужно около 3 ГБ на время работы. Можно освободить место или выбрать другой диск для временных файлов. | Удалить временные — 2,1 ГБ · Сменить папку |

## 7. Что из этого уже в ядре

Сделано 16.09.2026, этап M2:

- **чувствительность к речи** — три положения, порог VAD 0.65 / 0.5 / 0.35;
- **обрезка тишины по краям** — средствами ffmpeg, середина не трогается;

Ждут своего этапа: `JOB_ABORTED` и `DOWNLOAD_FAILED` пока никто не поднимает —
первый нужен при обрыве видеокарты, второй появится вместе с загрузчиком на M4.
