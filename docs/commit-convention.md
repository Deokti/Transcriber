# Соглашение о коммитах

Проект следует [Conventional Commits 1.0.0](https://www.conventionalcommits.org/ru/v1.0.0/).
**Префикс и контекст — по-английски, описание и тело — по-русски.**

## Формат

```
<тип>[(контекст)][!]: краткое описание

[тело]

[сноски]
```

- тип — существительное из списка ниже, затем необязательный контекст в скобках, необязательный `!`, затем двоеточие и пробел;
- описание идёт сразу после двоеточия;
- тело отделяется от описания пустой строкой и может состоять из нескольких абзацев;
- сноски отделяются пустой строкой после тела, каждая — токен, разделитель `: `, значение. Пробелы в токене заменяются дефисом (`Reviewed-by`), исключение — `BREAKING CHANGE`.

## Типы

| Тип | Когда |
|---|---|
| `feat` | новая возможность приложения |
| `fix` | исправление ошибки |
| `docs` | только документация |
| `refactor` | правка кода без новой функциональности и без исправления ошибок |
| `perf` | ускорение |
| `test` | тесты |
| `build` | сборка, зависимости, упаковка |
| `ci` | автоматизация сборки и проверок |
| `chore` | рутина, не попавшая в остальные типы |
| `style` | оформление кода, не меняющее поведения |

`feat` поднимает MINOR-версию, `fix` — PATCH, критическое изменение — MAJOR.

## Контексты

По модулям из `architecture.md`:

`core` · `asr` · `media` · `quality` · `export` · `deps` · `platform` · `ui` · `cli` · `adr`

Контекст необязателен, но если изменение укладывается в один модуль — лучше указать.

## Описание

- с маленькой буквы, без точки в конце;
- до примерно 72 символов;
- по-русски, отвечает на вопрос «что делает этот коммит».

## Критические изменения

Обозначаются `!` перед двоеточием, сноской `BREAKING CHANGE:` или и тем и другим. Слова `BREAKING CHANGE` пишутся прописными; `BREAKING-CHANGE` — допустимый синоним. Если стоит `!`, сноску можно опустить, но лучше объяснить, что именно сломалось.

## Чего в коммитах не бывает

**Никаких подписей и водяных знаков.** В сообщениях коммитов и в описаниях пул-реквестов не должно быть строк, приписывающих авторство инструментам, которыми делалась работа: подписей, соавторства, пометок «сгенерировано с помощью…». Сообщение содержит только то, что относится к изменению.

## Примеры

```
feat(asr): выбор модели и устройства через профиль
```

```
fix(media): ffmpeg не находил дорожку при пробеле в пути
```

```
docs(adr): ADR-0002 — Qt Quick вместо виджетов
```

```
refactor(core): вынести оркестрацию из run.py в pipeline
```

```
chore(deps): поднять faster-whisper до 1.2.1
```

```
feat(export): сборка docx из сегментов

Абзацы склеиваются по паузам длиннее 1.5 секунды и по знакам конца
предложения. Тайм-код ставится в начале каждого абзаца.

Closes: #14
```

```
feat(ui)!: перейти на QML

Виджеты удалены полностью, окно поднимается через QQmlApplicationEngine.

BREAKING CHANGE: старые файлы тем в формате QSS больше не читаются,
палитра переехала в app/qml/Theme.qml
```
