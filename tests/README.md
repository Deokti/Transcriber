# Тесты интерфейса

```bash
python tests/run_all.py
```

Окно рисуется без экрана, поэтому ничего не мелькает и тесты можно гонять
параллельно с работой. Каждый тест — отдельный процесс: приложение Qt
в процессе может быть только одно, а тестам нужно разное начальное
состояние. Настройки читаются настоящие, но на диск ничего не пишется.

## Что здесь лежит

| Файл | Что проверяет | Откуда взялся |
|---|---|---|
| `test_language_keeps_theme.py` | смена языка не трогает тему и папки | тема слетала при переводе интерфейса |
| `test_marks_follow_theme.py` | нарисованные значки перекрашиваются вместе с темой | галочка оставалась тёмной на светлом фоне |

## Как писать новые

Каждый тест появляется из настоящей ошибки, а не из желания что-нибудь
проверить. Поэтому в начале файла — строчки о том, что именно ломалось.

Новый тест стоит один раз прогнать на сломанном коде и убедиться, что он
краснеет. Тест, который зеленеет всегда, хуже отсутствующего: он создаёт
ощущение проверки там, где её нет. Проще всего так:

```bash
git stash && python tests/run_all.py; git stash pop
```

Меряйте отношения, а не абсолютные числа. «Галочка светлее заливки» переживёт
смену палитры, а «яркость 253» сломается на первой же правке цвета.
